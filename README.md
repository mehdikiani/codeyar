# کُدیار (CodeYar) — دستیار ۱۰۰٪ آفلاین تدریس «طراح سایت ۱۴۰۵»

**کُدیار (CodeYar)** یک سامانه آموزشی تعاملی، خودکفا و **۱۰۰٪ آفلاین** است که به‌طور اختصاصی برای **هنرآموزان (دبیران) پایه یازدهم شاخه فنی‌وحرفه‌ای** جهت تدریس کامل کتاب درسی **«طراح سایت ۱۴۰۵»** (هر ۵ پودمان و هر ۱۰ واحد یادگیری) طراحی شده است.

این سامانه بدون نیاز به اتصال اینترنت در کارگاه‌های رایانه مدارس اجرا می‌شود و شامل محیط اجرای زنده **پایتون ۳**، **HTML5 / CSS3 / Bootstrap 5.3 RTL / JavaScript**، **پایگاه‌داده واقعی SQLite (WASM)** و **شبیه‌ساز Django MVT / ORM**، به همراه **حالت مدرس (Teacher Mode)**، **آزمایشگاه‌های شهود بصری**، **بانک تکالیف چاپی A4**، **آزمونک پای تخته** و **ارزشیابی دیجیتال شایستگی** است.

## امکانات کلیدی برای تدریس در کلاس و کارگاه

- **حالت مدرس (`Teacher Mode`):** با یک کلیک (یا کلید `T`) نکات گفتاری کلاس، توضیح خط‌به‌خط کد به فارسی روان، اشتباهات پرتکرار هنرجویان، پرسش‌های چالشی کلاس و کلید پاسخ اصلی + روش حل جایگزین تمام کارگاه‌ها و تکالیف نمایان می‌شود.
- **درسنامه خودآموز ۴ بخشی برای هر مفهوم:** (۱) چرا به این مفهوم نیاز داریم + تشبیه ملموس کلاسی، (۲) کالبدشکافی ساختار (Syntax Anatomy)، (۳) پشت صحنه چه اتفاقی می‌افتد، (۴) نکات طلایی و مقایسه «روش اشتباه ✗» در برابر «روش استاندارد ✓».
- **۴ سطح مثال اجرایی در هر مبحث:** پایه (`Basic`)، کاربردی (`Practical`)، ترکیبی (`Combined`) و مقایسه/خطای عمدی (`What-If`).
- **موتورهای اجرای ۱۰۰٪ آفلاین درون مرورگر:**
  - **پایتون ۳ آفلاین:** اجرای غیرمسدودکننده `input()` داخل ترمینال (بدون پنجره مزاحم مرورگر)، اجرای گام‌به‌گام با نمایش زنده متغیرهای حافظه RAM، فایل‌سیستم مجازی برای `pathlib.Path` / ماژول محلی `.py` / JSON، و بوم گرافیکی `turtle`.
  - **سندباکس وب آفلاین:** پیش‌نمایش زنده HTML/CSS/JS همراه با تزریق آفلاین Bootstrap 5.3 RTL و مسدودسازی خودکار لینک‌های CDN خارجی.
  - **SQLite واقعی (WASM) + شبیه‌ساز Django ORM و Template:** اجرای دستورات واقعی SQL (`SELECT`, `INSERT`, `DELETE`)، ترجمه زنده دستورات ORM جنگو به SQL و رندر قالب‌های جنگو (`{% if %}`, `{% for %}`, `{{ ... }}`).
- **ابزارهای کلاسی آماده:** حالت ویدئوپروژکتور (`P`)، بزرگ‌نمایی قلم (`A+`/`A-`)، تم تاریک/روشن (`D`)، بانک تکلیف با خروجی برگه A4 آماده چاپ، آزمونک تعاملی پای تخته، یادداشت‌های اختصاصی مدرس و ارزشیابی شایستگی با محاسبه خودکار مراحل کلیدی (ستاره‌دار) و خروجی CSV فارسی سازگار با اکسل.

### میانبرهای صفحه‌کلید (سازگار با چیدمان فارسی و انگلیسی)

## پیش‌نیازها (Prerequisites)

برای دریافت، آماده‌سازی و اجرای پروژه روی رایانه خود، فقط به دو ابزار رایگان نیاز دارید:

1. **Node.js نسخه ۲۰ یا بالاتر (پیشنهاد: نسخه LTS)** — همراه با `npm`
   - برای بررسی نصب بودن در ترمینال (CMD یا PowerShell یا Terminal):
     ```bash
     node -v
     npm -v
     ```
2. **Git** (اختیاری — در صورت تمایل می‌توانید پروژه را به‌صورت فایل ZIP نیز از گیت‌هاب دانلود کنید).

> **توجه:** در این سامانه **هیچ کلید API یا اتصال به اینترنت برای کاربری روزمره لازم نیست**. فایل `.env.example` فقط الگوی استاندارد محیط توسعه است و برای اجرای آفلاین در مدرسه نیازی به ساخت فایل `.env` ندارید.

## نصب و راه‌اندازی گام‌به‌گام (برای دبیران پس از Clone کردن مخزن)

### گام ۱: دریافت مخزن (Clone)

```bash
git clone <REPO_URL>
cd <PROJECT_FOLDER_NAME>
```

*(اگر پروژه را به‌صورت ZIP دانلود کرده‌اید، فایل را از حالت فشرده خارج کنید و ترمینال را در پوشه پروژه باز کنید.)*

### گام ۲: نصب وابستگی‌ها (فقط یک‌بار با اینترنت)

```bash
npm install
```

این دستور تمام کتابخانه‌ها از جمله **فونت فارسی Vazirmatn**، **فونت کد JetBrains Mono**، **Bootstrap 5.3 RTL**، **CodeMirror 6** و **sql.js (SQLite)** را به‌صورت محلی نصب می‌کند.

### گام ۳: آماده‌سازی فایل‌های باینری ۱۰۰٪ آفلاین (فقط یک‌بار با اینترنت)

```bash
npm run setup:offline
```

این اسکریپت به‌طور خودکار دو کار انجام می‌دهد:
1. فایل موتور پایگاه‌داده `sql-wasm.wasm` را از `node_modules` به مسیر `public/vendor/sqljs/sql-wasm.wasm` کپی می‌کند (برای پودمان ۵).
2. هسته آفلاین **Pyodide** (حدود ۲۵ مگابایت) را در مسیر `public/vendor/pyodide/` ذخیره می‌کند.

> **اگر دانلود Pyodide به دلیل محدودیت اینترنت ناموفق بود:** نگران نباشید! دستور زیر را بزنید تا فقط فایل SQLite کپی شود:
> ```bash
> npm run setup:offline -- --sql-only
> ```
> موتور داخلی پایتون ۳ آفلاین کُدیار به‌صورت پیش‌فرض و بدون نیاز به Pyodide **تمامی ۲۶۹ قطعه کد پایتون کتاب درسی** را به‌صورت فوری و گام‌به‌گام اجرا می‌کند.

### گام ۴: اجرای سامانه

```bash
npm run dev
```

سپس مرورگر (Chrome، Edge یا Firefox) را باز کنید و وارد نشانی زیر شوید:

```text
http://localhost:3000
```

## راهنمای استقرار ۱۰۰٪ آفلاین روی فلش (USB) برای کارگاه بدون اینترنت مدرسه

پس از اینکه یک‌بار در خانه (در حالت آنلاین) مراحل ۱ تا ۳ بالا را انجام دادید، خروجی نهایی آماده اجرا را بسازید:

```bash
npm run build
```

این دستور کل اپلیکیشن (شامل تمام فونت‌های فارسی، آیکون‌ها، بوت‌استرپ، کدهای ۱۰ واحد یادگیری و فایل‌های `public/vendor/`) را در پوشه **`dist/`** جمع‌آوری می‌کند.

### روش الف (ساده‌ترین روش — بدون نیاز به Node.js در کارگاه مدرسه!)

از آنجایی که روی تمام سیستم‌های کارگاه رشته کامپیوتر **پایتون ۳** نصب است، کافی است **فقط پوشه `dist/`** را روی فلش (USB) کپی کنید و در کارگاه مدرسه یکی از دستورات زیر را در CMD / Terminal داخل پوشه پروژه اجرا کنید:

```bash
# روی ویندوز / لینوکس / مک با پایتون ۳ (بدون نیاز به Node.js و بدون اینترنت):
python -m http.server 3000 --directory dist
```

*(در برخی سیستم‌های ویندوز ممکن است دستور `py -m http.server 3000 --directory dist` باشد.)*

سپس مرورگر را روی `http://localhost:3000` باز کنید.

- **اشتراک‌گذاری در شبکه داخلی کارگاه (LAN):** اگر سیستم‌های هنرجویان به شبکه محلی کارگاه متصل هستند (حتی بدون اینترنت)، با اجرای دستور بالا هنرجویان نیز می‌توانند از مرورگر سیستم خودشان با آدرس IP سیستم هنرآموز (مثلاً `http://192.168.1.10:3000`) وارد سامانه شوند!

### روش ب (در صورت نصب بودن Node.js در کارگاه)

کل پوشه پروژه (شامل `node_modules/` و `dist/`) را روی فلش کپی کنید و در کارگاه دستور زیر را اجرا کنید:

```bash
npm run preview -- --port 3000 --host
```

> **هشدار مهم:** فایل `dist/index.html` را با **دوبار کلیک مستقیم** (`file://...`) در مرورگر باز **نکنید**؛ مرورگرها به‌دلیل محدودیت امنیتی CORS اجرای ماژول‌های ES و موتور WebAssembly (SQLite) را روی پروتکل `file://` مسدود می‌کنند. همیشه از سرور محلی (`http://localhost:3000`) استفاده کنید.

## پشتیبان‌گیری و انتقال داده‌های کلاس (نمرات و یادداشت‌ها)

تمامی اطلاعات شما — شامل **فهرست هنرجویان و نمرات ارزشیابی شایستگی**، **تیک واحدهای تدریس‌شده**، **یادداشت‌های اختصاصی مدرس** و **کدهای ویرایش‌شده** — به‌صورت ۱۰۰٪ خصوصی و محلی در حافظه مرورگر (`localStorage`) ذخیره می‌شود و به هیچ سروری ارسال نمی‌گردد.

- **انتقال بین لپ‌تاپ شخصی و سیستم مدرسه:** در پایین نوار کناری روی دکمه **«پشتیبان JSON»** کلیک کنید تا فایل پشتیبان دانلود شود؛ سپس در سیستم دیگر با دکمه **«بازیابی»** دقیقاً همان وضعیت را بارگذاری کنید.
- **خروجی اکسل نمرات:** در تب **«۸. ارزشیابی»** هر واحد یادگیری، دکمه **«خروجی CSV (اکسل)»** فایل کارنامه شایستگی را با کدگذاری UTF-8 BOM تولید می‌کند تا حروف فارسی در Microsoft Excel بدون به‌هم‌ریختگی نمایش داده شوند.

## عیب‌یابی خطاهای رایج در کارگاه مدارس

1. **خطای PowerShell در ویندوز (`running scripts is disabled` / `npm.ps1 cannot be loaded`):**
   - یا از **Command Prompt (`cmd`)** به‌جای PowerShell استفاده کنید، یا یک‌بار در PowerShell دستور زیر را بزنید:
     ```powershell
     Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
     ```
2. **پورت ۳۰۰۰ اشغال است (`Port 3000 is already in use`):**
   - سرور را روی پورت دیگری اجرا کنید (مثلاً `3005`):
     ```bash
     npx vite --port 3005
     ```
     یا در حالت پایتون روی پوشه `dist`:
     ```bash
     python -m http.server 3005 --directory dist
     ```
3. **صفحه سفید پس از کلیک روی `dist/index.html`:**
   - مطابق بخش استقرار آفلاین، حتماً پوشه `dist` را از طریق یک سرور محلی (`python -m http.server 3000 --directory dist` یا `npm run preview`) باز کنید و از `file://` استفاده نکنید.
4. **چگونه مطمئن شویم پس از تغییر کد، همه مثال‌ها سالم‌اند؟**
